# PLP Python Week 4 Assignment

This repository contains my Python Week 4 assignment, which focuses on creating and using functions.

* **welcome.py:** Defines a `welcome()` function that returns greeting messages for different names.
* **toolbox.py:** Defines and tests three functions: `double()`, `is_pass()`, and `greet()`.

The hardest function for me to write was `greet()` because it uses a default parameter. I learned how to set a default greeting and how to provide a different greeting when calling the function.
